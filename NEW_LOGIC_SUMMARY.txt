KEY ALGORITHMS

A* PATHFINDING
--------------
fCost = gCost + hCost
  gCost: Actual distance from start
  hCost: Manhattan distance to goal

Steps:
1. Start with initial position
2. Explore neighbors with lowest fCost
3. Avoid obstacles and enemies
4. Return optimal path

Performance: 2-5ms average, max 100 iterations

================================================================================
PATHFINDING ALGORITHM EXPLAINED
================================================================================

A* ALGORITHM:

Input: Start position, Goal position
Output: Optimal path or empty array

Process:
  1. Initialize open list with start node
  2. While open list not empty:
     a. Get node with lowest fCost
     b. If node is goal, reconstruct path
     c. Add node to closed list
     d. For each neighbor:
        - Calculate costs (g, h, f)
        - Add to open list if not visited
        - Update if better path found
  3. Return path or empty if not found

Cost Calculation:
  gCost = distance from start
  hCost = Manhattan distance to goal
         = |x1 - x2| + |y1 - y2|
  fCost = gCost + hCost

Example:
  Start: (0, 0)
  Goal: (3, 4)
  hCost = |0-3| + |0-4| = 7

  Path: [(0,1), (0,2), (1,2), (2,3), (3,4)]
  Length: 5 moves
