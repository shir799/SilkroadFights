## 🚀 Usage

### Quick Start (3 steps)

**1. Wrap app with ThemeProvider:**
```tsx
<ThemeProvider defaultTheme="classic-desert">
  <App />
</ThemeProvider>
```

**2. Use ImprovedGameBoard:**
```tsx
<ImprovedGameBoard
  weather="sandstorm"
  timeOfDay="dusk"
  showCoordinates={true}
  {...gameProps}
/>
```

**3. Add VisualEffects:**
```tsx
<VisualEffects effects={effects} />
```

**That's it!** Full documentation in the integration guide.
