## ✅ QUALITY STANDARDS

### Visual Assets
- **Format:** PNG-24 (transparency) or JPG (backgrounds)
- **Optimization:** TinyPNG or similar
- **Max Size:** 100KB (sprites), 500KB (backgrounds)
- **Style:** Consistent across all assets
- **Readability:** Clear at target size

### Audio Assets
- **Format:** MP3 (192kbps for SFX, 256kbps for music)
- **Sample Rate:** 44.1kHz
- **Normalization:** -6dB to -3dB peak
- **Max Size:** 200KB (SFX), 5MB (music)
- **Looping:** Seamless for music and ambient

### Performance Targets
- **Page Load:** < 3 seconds
- **Frame Rate:** 60 FPS
- **Memory Usage:** < 200MB
- **Bundle Size:** < 10MB total

## 🐛 COMMON ISSUES & SOLUTIONS

### Issue: Assets not loading (404)
**Solution:** Check file paths, case sensitivity, file extensions

### Issue: Sounds not playing
**Solution:** User must interact first (click), check format (MP3)

### Issue: Images pixelated/blurry
**Solution:** Use `image-rendering: pixelated` CSS, disable Next.js optimization for pixel art

### Issue: Performance slow
**Solution:** Implement preloader, sprite sheets, lazy loading
